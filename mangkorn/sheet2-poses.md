# Mangkorn: Sheet 2, Key gestures and postures

Purpose: lock the key gestures and body postures so the dragon stays consistent across emoji.

Attach as reference: the Quest poster, the three dragon stickers, and the finished Sheet 1 image.

## Prompt

```
Using the attached images AND the attached character design sheet as the exact character reference, create ONE pose reference sheet, landscape 3:2, plain flat white background, 16-bit pixel art style with bold dark outlines, cute chibi proportions. The dragon must look IDENTICAL in every pose: same face, horns, crown, scale pattern, wing shape, colors and proportions.

Grid of 12 poses, 4 columns × 3 rows, every pose the same size and the same ground line:
Row 1 (arms and hands): 1) one arm raised high, waving; 2) both arms down, relaxed; 3) both paws held up near the cheeks; 4) both paws forming a heart in front of the chest.
Row 2 (arms and hands): 5) thumbs-up; 6) both paws pressed together (apologizing); 7) both fists pumping up (cheering); 8) arms crossed in an X.
Row 3 (body postures): 9) standing, wings folded; 10) wings fully spread open; 11) bowing forward politely; 12) curled up asleep with wings wrapped around the body.

Text: only a small number under each pose (1 to 12). No other text. No scenery, no ground shadow.
```
