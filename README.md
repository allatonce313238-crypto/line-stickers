# line-stickers

Prompts and notes for LINE stickers and animated emoji.

## Mangkorn (red dragon) emoji set, 16 emoji

Plan: ChatGPT makes one clean base image per emoji; the animation and APNG are built in code (cut-out animation). No Kling credits.

| File | What it is |
|---|---|
| [mangkorn/sheet1-identity.md](mangkorn/sheet1-identity.md) | Turnaround, expressions, palette, parts breakdown |
| [mangkorn/sheet2-poses.md](mangkorn/sheet2-poses.md) | 12 key gestures and postures |

## How to use

1. Generate Sheet 1 with the poster and dragon stickers attached.
2. Generate Sheet 2 with Sheet 1 attached as well.
3. For each emoji, attach both sheets and ask for one clean image on a plain green background.

## LINE animated emoji specs (from LINE's guidelines)

- 8 to 40 emoji per set, plus one chat tab image (96 x 74 px, static PNG)
- 180 x 180 px each, APNG saved with a .png extension
- 5 to 20 frames, maximum 4 seconds, whole seconds only
- The first frame is the still image
- File size limit not confirmed: check the current guideline page before submitting
